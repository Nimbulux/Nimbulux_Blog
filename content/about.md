## 关于

一个扁平化、淡色系的博客模板。

### 结构

| 文件 | 作用 |
| --- | --- |
| `app/js/config.js` | 全部配置：站点信息、页面清单、路径、文案、配色 |
| `app/content/*.md` | 主页 / 好友 / 关于 的正文 |
| `app/pages/<页面>/` | 每个页面一个目录：`index.html` + 自己的 js + 自己的 css |
| `posts/` | 文章构建产物：`list.json` + `page.md` / `page.enc` |

### 说明

- 页面是普通网页，直接打开就能用；站内链接是真实跳转
- 文章页右侧的目录树可以翻全部文章，自带搜索
- 代码高亮、Markdown 解析、加密文章的解密都是**按需加载**的
